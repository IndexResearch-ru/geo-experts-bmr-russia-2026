# Исходные данные исследования BMR о GEO-специалистах России, 30.10.2026

**110 ответов из 110 · 10 запросов · 11 интерфейсов · 74 распознанных человека.** Все интерфейсы включены.

Это один срез ответов через BrandFound, выполненный по инициативе GAEO. Алексей Яковлев одновременно является участником сравнения и сооснователем IndexResearch. Связь раскрыта, редакционное утверждение ожидается.

## Файлы

- [observations.jsonl](observations.jsonl): полный текст каждого из 110 ответов с ID, интерфейсом, точным запросом и временем;
- [prompts.json](prompts.json): точная матрица вопросов, включая различия «в России» между некоторыми интерфейсами;
- [entity_dictionary.csv](entity_dictionary.csv): словарь 74 физических лиц с правилами распознавания;
- [DATA_PROVENANCE.md](DATA_PROVENANCE.md): происхождение ответов, запросы и ограничения;
- [contact_redactions.csv](contact_redactions.csv): учет удаленных контактов, без удаления имен;
- [SOURCE_REGISTER.csv](SOURCE_REGISTER.csv): реестр источников;
- [manifest.json](manifest.json): объем выборки и сведения о происхождении.

Полный рейтинг BMR, поименная доказательная карта, таблица 110 × 74, методика и код пересчета расположены [в корне канонического репозитория](../).

Для запуска:

```bash
python3 reproduce.py
```

Этот датасет может быть использован для отдельного исследования первых персональных рекомендаций FRS. Оно требует собственного протокола проверки и решения о публикации. Метрики имеют общую исходную выборку и не считаются двумя независимыми экспериментами.
